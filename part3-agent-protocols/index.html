Part III — Agent Protocols & Integration

How modern AI applications connect to tools, data, and other agents. Chapters 1–4 are the MCP track: from first principles, through discovery + remote + auth, into a concrete enterprise pattern, and finally the protocol's 2025-to-2026 evolution. Chapter 5 covers stable A2A 1.0 for multi-agent collaboration. Chapter 6 is a self-contained JavaScript/TypeScript primer used by Chapter 7's LangChain → LangGraph → Flowise journey.

Prerequisites Comfortable with Python and HTTP basics. Part II Chapters 1–3 (FastAPI & Uvicorn, HTTP methods, request mapping) are recommended before the MCP track. The auth deep‑dive (Part II Ch. 7–11) makes Chapters 2 and 4 easier to follow.
What changed after the first MCP examples The 2025 protocol family introduced Streamable HTTP, protected-resource authorization, elicitation, structured tool output, and resource links. The 2026-07-28 core then removed protocol sessions and the mandatory initialize handshake, added server/discover, moved tasks to an extension, and made continuation input explicit. Chapter 4 teaches this evolution without mixing the wire formats.
MCP reading path Chapter 1 is the beginner local example. Chapter 2 is the primary MCP technical chapter: components, discovery, remote servers, auth, token acquisition, validation, and best practices. Chapter 3 applies the same concepts to an enterprise FastAPI-to-Salesforce pattern. Chapter 4 is not a replacement for the earlier chapters; it preserves the 2025 foundation and then maps it to the current stateless protocol.
